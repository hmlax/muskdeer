# 固定价位现货网格

P07.1实现纯报价算法`quoting.Grid`，P07.4接入现有持久策略控制器，管理API仍待后续。参数沿用已生成的typed GridParameters；资金、价格、数量和费用使用decimal，接口小数继续为string。

`grid_count` 表示含上下界的等差价位数量，范围 2..200。第 i 级的精确有理价格为 `lower + (upper-lower)*i/(count-1)`；先直接除以价格 tick 求整数 tick，BUY向下、SELL向上，不提前舍入等分间距。参考价下方为BUY，上方为SELL，与参考价完全相同的一级不挂单。量按 lot 向下取整，低于最小名义金额的级别跳过。

固定级别按价格升序分配。每单不超过 per_order_notional，两侧合计不超过 total_budget；BUY现金包含quote费用，全部BUY剩余量加实际库存不超过inventory_limit，未确认SELL不释放库存空间。SELL只分配实际已有且可用的base，不开现货空仓。初始化不会购买或补入base；零base可只生成BUY，达到库存上限可只生成SELL，零资金不生成订单。

所选来源/模式/交易对、发布授权和行情完整性/时效仍须匹配。参考价越过区间返回明确的保护原因，交给控制器停止新报价并处理旧单；算法不修改生命周期。跨越实际本地最优价的级别跳过，不平移成另一网格价格。区间不足以容纳不同tick价位时拒绝参数，取整落到区间外的端点跳过。

沿用同一目标差分：价格触达不算成交；核心/OMS才是部分或全部成交依据。部分成交后实际剩余量与完整目标量不同时先撤旧单，等待终态才允许补单；UNKNOWN或撤单未确认阻止补单，不自行推定成交。差分目标上限扩展到现有单实例200个活动订单上限，纯算法不取得授权、不预留预算或发送订单。

控制器按实例及实际参数的同一模板选择算法，拒绝缺失、混合或不匹配的typed参数，不能回退为另一模板。沿用环境的一致快照、所选行情、四级预算裁剪、共享最坏BUY库存、持久Plan/Attempt及核心最终fence。网格差分的reprice容忍为0，必须匹配确切固定价位；最小刷新100ms、订单维护年龄上限1小时，安全且未变的价位不会沿用做市的短周期换单。保护撤单绕过刷新节流，小时维护也先确认撤单终态才替换。

参考价越界或不可用进入RECOVERING保护，仍保持用户运行意图；确认撤清前不补单。所选参考价回到区间后按既有恢复流程重新报价，不切到其他来源。实际PG/race已覆盖binance绑定的固定四级、稳定保持、越界实际撤单/回归及停止等待核心终态；完整管理启停、独立进程网格及两来源浏览器集成继续后续P07，不据此声明完整网格管理已交付。验证见[P07.1](validation/P07-01.md)和[P07.4](validation/P07-04.md)。
