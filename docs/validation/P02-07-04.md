# P02.7.4：发现与认证的 unary RPC 工厂

日期：2026-10-27。关联 R09、A02/A26 的调用链部分；完整 P02 尚未完成。

## 范围

新增 GRPCClients Proto/生成配置、deer/rpcclient.Factory 及借用 getter Deer.GRPCClients()。Factory 在 Nacos 后初始化、之前关闭；API 复用同一 Deer 工厂。配置要求 mTLS、1–16 个允许的服务、1–64 个在途调用、1–16 MiB 消息上限及明确的连接/请求期限；根配置要求 Nacos，客户端请求预算不超过停止预算。

Client(Target) 返回兼容生成 unary client 的 facade，不连接网络。Invoke 使用调用上下文，总预算涵盖准入等待、实时发现、mTLS 建连、RPC；指定实例缺失不回退，无实例列表缓存或地址 fallback。配置/凭据独立快照。请求/响应为 typed Proto，发送前校验 Proto 大小，调用选项不能提高上限。每次请求关闭其连接，Close 撤销准入、取消并 join 在途操作；关闭后不重新连接。

禁用服务配置重试并在业务 SendMsg 前固定 stream，避免 SDK 透明重放；完整权衡、受锁定版本保护的行为及原始 HTTP/2 负对照见 [ADR 0004](../decisions/0004-bounded-unary-rpc.md)。目前明确只支持 unary，流返回 Unimplemented。

## 检验范围

单元场景覆盖 typed 小数字符串响应、消息上限、业务 Unavailable 不重放、每次实际发现、指定 owner 缺失不回退、发现失败不使用旧地址、仅允许配置服务、等待准入的 caller deadline、配置默认 deadline、Close 取消并 join 在途 RPC、终态关闭和纯配置拒绝。

原始 mTLS HTTP/2 REFUSED_STREAM 测试在客户端已处理拒绝后才编码业务消息：保留实现请求一次，移除发送前固定操作的负对照观察到两次并失败。负数重试缓存曾触发 SDK 空指针，已删除并保留诊断结论，未以该参数配置生产路径。

新增真实基础设施场景：隔离 Nacos 中两个 mTLS Deer 节点，通过 DeerApi/Hertz route 获取其共享工厂，按实例发现并调用 ArithmeticProbe；HTTP/JSON 小数字符串 `0.1 × 0.2 = 0.02`，RPC response header 证明实际实例。停止 A 后 A 请求返回 503，B 继续成功；关闭共享工厂后 API CheckReady 返回 ErrClosed。测试 CA/私钥只在 TempDir 生成，公共 testcert helper 不在生产进程初始化。

实际通过 make fmt、make verify（Go 1.27.3、Proto/hz 生成、格式/lint、5 项 Python、Go 单元/race/构建）、integration tag vet、make integration、文档/差异检查。完整集成回归原 PostgreSQL 5+6、Redis 6、JetStream 8、Nacos 查询 4、发布生命周期 2 组，并新增 1 组 API/安全 RPC 链路；临时四容器和网络均已清理。
