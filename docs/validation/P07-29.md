## 行为

当前 operator/admin 可显式关闭一个策略；当前 admin 恢复需绑定独立风险版本、requested 配置版本和 desired 目标，并检查义务、共享门禁、对账、所选行情及请求/共享库存硬限。资金预算 Revision 与管理版本分离，旧单的实际预留/冻结、运行目标、实际状态、配置及所有权保留。关闭不阻止原协议下撤单；恢复也不直接激活、启动或签发许可。

审计、开关、缓存风险关闭及不可变收据同事务，当前权限/CSRF 在重放前检查。提交时 SQL 独立检查到期、角色、审计与实际效果，恢复证明必须在当前选择行情/租约/参数年龄及 5 秒上限内仍有效。直接核心提交同样遵守已管理策略的关闭旗标，包括 intent ID 为零的调用；未管理裸核心历史合同保留。
