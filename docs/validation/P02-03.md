# P02.3：JSON 日志、实例文件及同步轮转

日期：2026-10-26。范围：日志核心、配置 Proto 与 Deer/DeerApi 装配，关联 A02/A03/A26 的日志部分。

## 实现

- Logging/LogFile 配置从 Proto 生成；缺省 stdout INFO，显式配置需至少一个输出。文件大小 1..1024 MiB、保留数为正、保留天数 1..36500；非法配置在业务依赖装配前失败。
- 每个实例拥有 JSON handler、独立日志文件/锁和错误状态，API 复用一个 Deer。日志最后释放，其他依赖清理时仍可写入；构造失败释放文件锁。
- stdout/file 输出一致，支持级别过滤、Kratos 键值桥接、明确的写错误和幂等关闭。结构化 key/group 脱敏，根身份不能被覆盖，decimal 无损字符串；不把任意结构对象序列化进日志。
- 固定 lumberjack v2.2.1 的 MIT 源码维护版本，保留来源/原文件校验和；改为同步压缩/保留，无后台 worker，避免快速轮转覆盖。见 [ADR 0002](../decisions/0002-owned-logging.md)。

## 测试证据

先添加所有权行为测试，复现上游四项语义失败，并在单独测试中通过 goleak 复现 millRun 残留；日志封装测试先确认缺少实现导致编译失败，再实现。

测试覆盖两个实例文件隔离、相同文件独占锁/重启释放、关闭后拒绝写入、并发整行 JSON、stdout/file 一致、筛选级别、输出错误保存、凭据 group 脱敏、内联 group 身份保护、错误 MarshalJSON 防绕过、精确 decimal、真实大小轮转、gzip、保留天数/数量及快速轮转。600 条 JSON 记录触发两个压缩备份，逐条读取所有备份和当前文件验证无丢失/重复。

固定 Go 1.27.3：make verify（生成一致性、hz 双次生成/编译、格式、lint、4 项工具链门禁、Go 单元/race 及构建）和 python3 scripts/go.py vet ./... 通过。28 项 Deer、12 项日志、7 项轮转顶层测试通过；包括最终目录路径拒绝、根 group/大小写保护和独立年龄/数量保留回归。24 份文档本地链接及 git diff --check 通过。旧 PostgreSQL fixture 作为 CI 回归，不代表新增业务存储。
