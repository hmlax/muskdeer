# P03.5 Typed 模板参数及精确校验

日期：2026-10-27。关联 A01/A22/A23/A24、R02/R04。

- common Proto 定义 MakerParameters/GridParameters 及 typed oneof；Model 直接引用具体消息并通过生成 GORM JSONB serializer 存储。无手写 PO、无新依赖，结构路线按固定 GORM v1.31.2 的原生 JSONSerializer 源码核对并实测，未手改生成物。
- domain/strategyconfig 显式 string→decimal、整毫秒→有界 duration、typed union/schema 边界；校验精确预算、价差/档位、库存、刷新/行情时效、显式对冲开启/关闭及网格范围。仅库存/金额等参数自身交叉校验，实际账户/行情/租约许可不在本步骤冒充。
- 单元/race：18 位小数预算刚好覆盖通过，少一个最小单位失败；非法格式/精度、计数、时间溢出、库存倒置、空/未知/typed-nil union、legacy/future schema、unknown Proto、对冲组合均验证；无 raw JSON/float 中间值。
- 实际 PostgreSQL 版本 3：两模板的 generated Model typed JSONB 全字段 proto.Equal 往返；拒绝未来/空/双参数、模板 FK 错配、未知键和将小数写成 JSON number；原 v1 升级、来源/active 恢复、nullable/Model、并发/回滚/CLI 等完整集成仍通过。
- make generate/contract-check、fmt、verify、最终 lint/vet、完整 make integration、文档/差异检查通过，race/goleak 保留；随机 schema 和 Compose 容器/网络/卷均清理。

当前参数 schema=1、数据库迁移版本3；legacy metadata-only 行不提供可运行参数。尚无管理操作、策略报价或实盘；下一步继续 typed 交易合同、执行模型、模拟器及 fencing。[CI 40444711131](https://github.com/hmlax/muskdeer/actions/runs/40444711131) 已确认上一步来源身份实现 success，本步骤推送后核验新 CI。
