# P01.1：项目 Go 工具链固定

日期：2026-10-26。需求：Go 1.27.3、module github.com/hmlax/muskdeer、逐步验证后提交/推送。

## 选择与依据

- 官方下载清单列出稳定版 go1.27.3；本地默认编译器是 go1.26.1，通过项目缓存获取并运行 go1.27.3 darwin/arm64。
- .go-version 与 go.mod 声明 1.27.3；scripts/go.py 强制 GOTOOLCHAIN=go1.27.3，并在执行实际命令前检查 GOVERSION。仅声明 go.mod 的最低版本不能保证实际编译器精确一致。
- 模块缓存、编译缓存、GOPATH/GOBIN 放在忽略提交的 .cache；后续 Go 命令统一使用 python3 scripts/go.py 或调用该脚本的 make 目标。
- 官方依据：[下载清单](https://go.dev/dl/?mode=json&include=all)、[Go 工具链选择](https://go.dev/doc/toolchain)。

## 验证

| 命令 | 预期及本步结果 |
|---|---|
| make doctor | go version go1.27.3 darwin/arm64 |
| make test-tooling | 编译器正确时保留参数；错误版本/探测失败不执行命令；实际命令失败保留退出码，共 4 项通过 |
| git diff --check | 无空白错误 |

本步没有业务 Go 包，不以空包测试或构建宣称交易功能完成。protoc 29.3、Docker Engine 29.9.2 可用；后续步骤验证生成器与真实隔离 PostgreSQL，当前未运行这些兼容性测试。
