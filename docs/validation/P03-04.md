# P03.4 策略来源与交易对身份持久化

日期：2026-10-27。关联 A01/A22/A23/A24、R04。

- strategy.proto 定义 Instrument、StrategyInstance、StrategyConfigVersion，全部直接生成 GORM 类型及四个公共字段；没有手写 PO 或 TableName。固定生成共 7 个 Proto Go 文件。
- 0002 增加交易对执行 metadata、实例身份/模板/账户/代码/修订/期望状态，以及配置历史的版本/来源身份。requested 与 active 的版本/来源分别保存；两组复合外键强制来源必须属于同一个实例的对应版本，初次创建通过同一事务的 deferred FK 完成。
- 交易对 tick/lot/min_notional 使用 numeric(38,18) 与 string，单位分别为 quote/base、base、quote；Go 计算保持 decimal，输入边界仍需按字段规则拒绝过精度，不能依赖 PostgreSQL numeric 自动舍入作校验。执行 venue 与行情源分离。
- 真实 PG 从仅有版本 1 的库升级到版本 2，旧记录字节/时间不变；四 writer 并发迁移及原失败回滚/历史/期限/CLI 回归更新并通过。做市 Binance、网格 OKX 共享交易对但独立来源；请求新版本时保留旧 active 来源，关闭 writer 后新连接恢复正确版本/来源及精确小数，另一实例不变。false 更新保留；DB 拒绝候选/版本来源错配且事务无残留。
- 三个新表实际 metadata 证明主键及必填时间，自动毫秒时间非零，delete_at 时间/NULL 往返通过。数据库场景只使用生成 Model，元数据 helper 传实际生成实例，无字符串选表。
- make generate/contract-check、fmt、verify、最终 lint、integration tag vet、完整 make integration 和文档/差异检查通过，race/goleak 保留，随机 schema 及 Compose 资源清理。初次长集成测试被复杂度门禁拒绝，拆为清晰的升级/恢复/公共字段断言后通过，没有放开阈值。
