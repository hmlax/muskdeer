# P02.1：公共资源所有权与初始化回滚

日期：2026-10-26。关联：A02 的资源初始化/清理前置行为；Deer/DeerApi 构造路径将在下一步骤接入。

deer 包新增 Cleanup 与 Initializer。初始化前校验整个资源计划，按顺序获取，成功及部分失败时保留释放操作；任一失败或调用方取消后逆序回滚，使用 errors.Join 保留初始化和释放错误。正常 cleanup 使用 sync.Once，重复及并发调用均只释放一次并返回同一错误结果。

清理在调用方同步执行；从调用上下文保留元数据并派生独立的超时上下文，避免构造时的取消阻止释放。资源回调必须遵守该清理上下文，管理器不启动脱离调用方的清理 goroutine。

## 验证

先添加行为测试，确认缺少实现时编译失败，再实现资源管理。7 项测试覆盖：原始错误与清理错误保留、逆序/重复释放、构造取消后的释放、8 个调用者并发 cleanup、计划无效时无副作用、失败资源自身的部分初始化释放、清理 deadline 及错误重复返回。

命令：python3 scripts/go.py test -race ./deer；make lint；make verify；git diff --check。race、goleak、lint 及现有生成/框架/持久化单元回归通过。

边界：当前未实现 NewDeer/NewDeerApi，也未初始化真实数据库、Redis、NATS 或 Nacos 客户端；本步骤只完成两个构造函数将共用的资源所有权层，不将 A02/A26 或整个 P02 标完成。
