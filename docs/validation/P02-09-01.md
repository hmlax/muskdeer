# P02.9.1：固定标签 Prometheus 指标

日期：2026-10-27。关联 P02 基础监控；完整 P02、A16/A26 尚未完成。

## 实现

新增 deer/metrics.Registry、Deer.Metrics()、标准 monitoring /metrics、HTTP/gRPC unary/stream 结果及延迟记录、独立 probe 分类、生命周期 gauge。只接受固定状态域，未知输入合并，未保存路径/身份/错误文本等任意标签。统计在实例内，不使用全局 registry、网络 exporter 或后台生产者；scrape 不计入自身，不查询依赖。

为遵守 Go 小数统一 decimal 的约定，整数纳秒直接转 decimal.Decimal 秒，sum 使用精确 Add；按 Prometheus 0.0.4 输出标准数值文本，不通过浮点中间值。固定累计 bucket/count/sum 一起复制后编码，避免在编码期间锁住请求路径。协议与指标含义见 METRICS。

格式门禁复用已有锁定的 prometheus/common v0.32.1（Apache-2.0）解析器，只将现有依赖标为测试直接使用，不升级版本、不引入生产浮点 collector。

## 检验

先写 Registry/HTTP 行为测试并确认缺实现/endpoint 时失败，再实现。

- 1ns + 2ns 输出精确 sum 0.000000003；counter/error/+Inf/count 和官方解析器通过。
- 八个并发记录者与并发 scrape，验证 count/+Inf 快照一致、无丢计数；异常 HTTP/gRPC 状态值不创建新标签。
- 两个真实 DeerApi 各自独立，2xx/4xx/error 正确；多次 scrape 内容不因自身请求改变；未知私有路径不进入输出。
- 真实 gRPC server 成功、参数错误及无期限流拒绝均进入正确状态 counter，错误数量正确。
- 固定 55440 导致两次容器启动失败后，先独立交付动态端口修复；使用 Docker 分配的 loopback 地址完整四种基础设施、两节点和 API mTLS/健康回归通过，临时容器/网络已清理。

实际通过 make fmt、make verify（doctor 示例、Proto/hz 生成、格式/lint、7 项 Python、Go 单元/race/构建）、integration tag vet、动态端口的完整 make integration 及文档/差异检查；race/goleak 保留。格式门禁不作为 Prometheus/Grafana 实际部署或容量证据。
