## 实现边界

- Nacos 配置明确 TCP host:port、namespace_id、group、cluster、username/password_env、连接/命令期限、max_inflight 1..64；namespace 不接受空或 public。TLS 默认开启，验证主机名且最低 1.2，可配置根证书；实连测试显式关闭 TLS。
- 标准 HTTP transport 使用调用上下文、独立连接池和配额；命令预算涵盖等待配额、认证与查询。不读环境代理，不接受 URL userinfo，不跟随重定向，响应最多 1 MiB，最多 1024 个实例。
- token 为私有内存缓存，缓存至服务端有效期的 80%，之后由下次操作刷新；登录并发合并且可取消。token 仅在 Authorization 头，密码只在登录 form；查询 URL 不携带秘密。401/403 清除对应缓存并将失败返回，不在同一操作自动登录重放；下一操作重新认证。
- 查询返回 typed Instance 值，不缓存实例列表；即使服务器保护阈值返回不健康实例，仍过滤 healthy/enabled/weight/cluster/protocol。第三方权重按其既有 JSON 数字协议读入 json.Number（底层 string），直接转 decimal.Decimal 比较，不引入 Go 浮点或业务数字接口。
- 校验 IP/端口、Deer 身份及重复身份，返回安全错误。APIError 保留 HTTPStatus/Code 和 errors.Is/As 原因，文本不输出口令、token 或响应体。仅配置端控制出站地址，业务服务名只作为有界转义查询参数。
- Close 原子撤销准入、取消并 join 所有已准入操作、释放连接，关闭后不会重开。客户端无全局状态/自建后台循环；Deer 在 JetStream 后初始化，API 失败逆序回收。

## 验证

单元/race/goleak 覆盖：8 个并发查询共用一次认证且每次实际请求；不健康、disabled、零权重、其他集群/协议过滤；关闭中断在途请求并拒绝重开；6 个纯配置拒绝分支；认证状态/敏感体不泄漏；token 被拒后只在下次调用刷新；认证重定向未访问目标；畸形/超大响应拒绝；Deer 注册缺失依赖时失败。

真实 Nacos 4 组场景：

1. 标准测试 fixture 注册一个带 typed metadata 的临时实例，实际认证查询返回其地址/Deer ID，另一个 namespace 看不到；重复关闭与关闭后拒绝查询。
2. 真实错误密码返回 403，保留安全类型，不暴露密码。
3. Deer Run 后实际 naming 健康成功，注入关闭后实时 readiness 返回 ErrClosed，正常停止回收。
4. DeerApi 路由初始化失败，借用的 discovery 已关闭。

注册/删除仅在测试管理 helper 中调用，不表示生产自动注册已实现。首轮实连暴露手册与 2.5.2 响应类型差异，已核对版本源码并将 fixture 严格断言为 code=0/data=`ok`；未接受任意成功字符串。安全审查将 token 从 query 移到已核验支持的 Bearer header，真实认证再次通过。

实际通过 make fmt、make verify（Go 1.27.3、生成/hz、格式/lint、4 项 Python、全部单元/race/构建）、make integration、带 integration tag 的 go vet、29 份文档本地链接及差异检查。现有 PostgreSQL 5+6 组、Redis 6 组、JetStream 8 组与原框架契约一并回归；临时四容器和网络均已清理。
