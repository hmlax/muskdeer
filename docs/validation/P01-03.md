# P01.3：框架与 RPC/HTTP 生成兼容验证

日期：2026-10-26，Go 1.27.3。需求：P01 框架兼容矩阵、接口小数 string/decimal、可重复生成，为 P02 Deer/DeerApi 提供已验证依赖。

| 组件 | 固定版本与用途 |
|---|---|
| Hertz | v0.10.6，HTTP 请求绑定和 JSON 字符串响应 |
| hz | v0.9.8，生成 HTTP 路由/handler 并复用既有 Proto DTO |
| Kratos | v2.9.2，gRPC 服务生命周期与有界停止 |
| gRPC / protoc-gen-go-grpc | v1.84.0 / v1.6.2，实际生成 stub 和协议往返 |
| Nacos SDK | v2.3.5，注册/发现/注销参数契约 |
| Kratos Nacos registry | v2.0.0-20260404020628-f149714c1d54，与上述 Kratos v2 配套 |
| Sonic / loader | v1.15.4 / v0.5.2，固定到明确支持 Go 1.27 的版本 |
| goleak | v1.3.0，框架测试结束后检查后台 goroutine 清理 |

版本与校验和由 go.mod/go.sum、tools/versions.json 固定。Hertz、Nacos SDK、gRPC 与 HTTP 注解为 Apache-2.0，Kratos 为 MIT；第三方注解源码及许可证原样保留在 third_party/hertz。

## 实际验证

- Kratos 启停真实 gRPC Server，经 bufconn 运行生成的客户端/服务端、Proto 编解码及 decimal 乘法；0.1×0.2 返回 string 0.02，非法价格返回 InvalidArgument，取消请求返回 Canceled，有界停止及 goleak 检查通过。
- Hertz BindAndValidate 直接绑定同一生成 DTO，JSON 响应小数为 string，正常查询返回 200，非法小数返回 400。query tag 从 Proto 的 tagger 选项生成；api.query 注解本身不会让标准 protoc-gen-go 添加 Go query tag。
- hz --use github.com/hmlax/muskdeer 配合 --trim_gopackage github.com/hmlax/muskdeer/，复用生成 DTO；在两个独立临时项目生成相同 Go 源码，编译生成的 route/handler，未产生第二份 protobuf 类型。临时 handler 仅验证生成兼容，不计为业务实现，不提交空模板服务。
- Nacos registry 使用具名 SDK fake 验证注册服务名/分组/端口、发现地址、注销及空服务名拒绝；这是 SDK 契约验证，尚未连接真实 Nacos，真实注册/发现和断连恢复由 P02 独立资源验收。
- Hertz 的默认 Sonic v1.15.0 对 Go 1.27 走兼容回退；实测后固定 Sonic v1.15.4，标准/Go race 测试均通过。不据此声称已达到交易延迟或容量目标。

命令：make tools；make generate；make verify；make integration；python3 scripts/go.py vet -tags=integration ./...；git diff --check。当前共有 6 项纯 Go 契约测试、5 组 PostgreSQL 场景和 4 项 Python 工具链门禁；生成一致性、hz 双次生成/编译、lint、race 与构建通过。

P01.2 远程 [Verify 运行](https://github.com/hmlax/muskdeer/actions/runs/40287708423) 已实测 success，含 Linux 生成、lint、单元/race、构建与真实 PostgreSQL；本步骤远程 CI 结果仍须以新提交实际运行记录为准。
