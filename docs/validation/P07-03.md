# P07.3 实际管理身份页面与 HTTP

日期：2026-10-28，关联R08/A18/A27的身份子流程；完整A18/A27仍未完成。

管理HTTP为api显式配置，通过DeerApi复用唯一Deer/PG连接并检查迁移，不迁移或创建默认账号。Hertz实现登录、当前会话和注销，严格Origin/Host、JSON边界、唯一canonical cookie及独立CSRF；HTTPS使用__Host-/Secure/HttpOnly/Strict，明确loopback HTTP开发用独立cookie名。响应不含秘密，拒绝/依赖故障固定JSON，API404/405不被页面吞掉。显式本地admin命令从命名环境变量读取口令，实际创建/审计同事务，命令参数/错误不回显秘密。

React/TypeScript/Vite实际页面从同源接口获取身份，支持坏凭据、加载、依赖错误、角色/固定到期、深路由刷新及注销；无默认凭据、虚构交易数据或浏览器持久bearer。产物及运行时许可编入Go，普通Go构建不依赖Node。Node/npm/前端依赖/Playwright锁定精确版本；官方Node归档4平台校验和、包锁、ignore-scripts、有界提取和目录穿越/越界链接/特殊文件拒绝；浏览器与缓存均在.cache。Docker只额外复制embed文件/产物，不复制node_modules。CI新增前端重建差异检查及真实浏览器流程，e2e包含该子流程。
