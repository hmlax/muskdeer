# 只做多百分比网格

沿用 `grid` 类型，模板 `long_grid_v1` 使用独立完整参数。原 `price_grid_v1` 固定区间网格、做市铺单及开发成交不改变。

用户本次规则：启动开首笔，跌1%买入一笔、涨1%卖出对应买入批次；价格达到撮合持仓均价下方0.5%时优先全平并停止。每笔目标100 USDT名义价值，10倍CROSS全仓保证金；“全仓”不代表消耗全部账户余额。0.5%止损通常先于第一档1%加仓，本次新配置按一笔100U名义上限保护；完整参数和上限均由数据库实例与账户策略提供。

- 数量按撮合lot向下取整，不超过每笔名义目标，可能显著小于100U。IOC部分成交只记录实际成交量，不假设整笔成交。实际买入均价由撮合成交名义量/数量计算，对应批次卖出同样只减实际剩余量。
- 买入使用撮合卖一作为限价，买回需满足所选源价格与撮合价格均不高于买回档。卖出需达到对应批次实际均价上方1%的价格，限价向上取tick。止损使用只减仓市价，触发价不保证为最终成交价。
- 对冲账户的真实多仓ID来自SDK观察，所有卖出显式reduce_only，不能开空仓。不自动采用既有外部仓位；未完成动作或游标数量与实际多仓不一致时暂停新增风险。
- 每次变化先记录动作并领取一次发送，进程退出/回执未知后不重发原请求。ACK按原生订单ID查询一条历史，UNKNOWN仅搜索当前专用账户的有限历史，缺失不是拒绝证据。独立保护循环可在未知开仓下平掉观察到的多仓，保持止损锁存并处理后到成交，确认所有在途动作及实际仓位归零才结束。
- 策略求值按实例频率，独立止损保护每500毫秒观察。控制暂停阻止新增开仓，已有持仓的止损保护保留；源不可用时仅使用新鲜撮合标记价减少风险。止损完成会版本化停止实例，显式启动才开始新轮，动作序号和历史不清零。
- 新增 `long_grid_runtimes` 与 `long_grid_actions` 只保存新网格的执行游标/动作，不是账户余额或持仓账本；无执行进程租约、所有权epoch及旧订单预留SUM。做市铺单及WashTrade继续各自零订单/零成交存储路径。

数据库显式升级到版本7：保留原1–5账本，版本6添加两张业务表和新模板，版本7扩展参数合同并允许不同账户绑定同一品种。旧三个模板和原实例/账户/交易历史不改写。维护升级要求四核心明确停止，应用启动仅检查版本，不执行DDL。

后台仍为独立admin项目，商户管理实例/账户/持仓；平台提供模板/品种/网关。参数通过强类型gRPC传递，管理库不直连交易库，不在Nacos合并业务默认参数。
