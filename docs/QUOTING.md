# 做市目标与执行保护

`internal/quoting.Maker` 是无 I/O 的目标计算器。输入明确的执行交易对元数据、实例所选来源/产品/模式、当前参考价与发布时间授权、参数、持仓、分配给本计划的可用资产及本所 BBO。输出最多 40 个由近到远交错排列的 POST_ONLY 买卖目标，不代表已接受的订单或资金预留。

基础价差为双边总价差，首档距离中心为一半，后续每档增加 level_spacing_bps。库存相对目标的偏差按 soft_limit 裁剪，最多使中心偏移半个基础价差；直接对精确有理表达式按 tick 向外舍入，不先近似除法。买价向下、卖价向上，数量向下按 step；本所对手价存在时价格保持被动，执行网关仍需检查实际撮合时的 POST_ONLY/STP。

各侧累计金额不超过 side_budget，每档不超过 level_notional。买方同时受含报价币手续费的可用现金和最坏买入后的库存硬上限约束；卖方同时受可用基础币和实际持仓约束，现货不做空。舍入后不足最小金额的档位省略。所有值先验证有界 decimal 精度，所选行情必须完整健康、来源/产品/模式准确、未过期且发布者授权有效；失败返回空目标和错误。

目标计算不代替 execution 对已有挂单、提交中和 UNKNOWN 订单的风险聚合、原子预算/资金预留及最终 fencing。控制器、差分、风险联动与失效撤单继续 P06 后续步骤；当前不能仅调用 Maker 宣称策略已经运行。
