# 策略报价的当前输入

repository.NewStrategyEnvironment借用根数据库，不领取租约、准备账户或开放风险。Current在只读REPEATABLE READ事务中核对传入的完整StrategySpec，读取当前active typed配置、精度、所选外部symbol、账户费用、核心有效最优买卖价及预算。传入版本已变则返回冲突，不把不同版本的字段拼成一次报价输入；没有所选绑定时不换其他行情源。

完整目标订单集的金额额度，取策略上限及账户/交易对/平台各自`上限 - 当前总预留 + 本策略已有预留`的最小值。加入自身预留只是避免保留现有订单时重复扣减；其他策略的INTENT/UNKNOWN/有效订单及未确认撤单仍占用原预留。另返回两类全局政策中的最低单笔上限。关闭、缺失或不一致的预算拒绝提供规划额度，不自动创建或启用。

LastRefresh取最近持久策略动作的原始创建时间，观察动作结果不重置报价刷新年龄。RiskAllowed只表示读取时现有许可的范围/来源/版本/时限满足，不能取代当前行情核验或最终execution原子准入。该输入不声称已为新目标冻结资产；OMS观察由typed执行客户端同步，真正提交仍须持久动作、当前策略与执行租约、全部预算及最终行情fence。

P06.15补充同一只读快照中的真实核心资产：Inventory为基础币available+frozen，AvailableBase/AvailableQuote为available加回本实例核心有效订单的实际剩余冻结额，供完整目标集规划。费用变化不用于重估旧冻结，其他实例冻结不加回；冻结和订单数不一致时关闭。OMS真实订单仍通过typed执行观察同步，规划输入不能冒充提交已获准。

MaximumBuyQuantity返回完整买单目标可用的共享最坏库存空间：最低active硬限减实际基础币总额，减其他实例非终态买单剩余量，最低为零。不用未确认卖单抵消风险；仍需最终原子库存门禁。

所有小数从数据库字符串直接解析为decimal.Decimal，账本及金额额度保留36位小数；不引入手写持久模型或浮点转换。P06.14只提供循环的输入仓库，实际策略任务和连续模拟另行验收。
