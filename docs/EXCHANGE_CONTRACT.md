# 现有交易所接入合同与缺失资料

2026-11-03 最新边界：Himalaya 已提供 Go SDK（模块 `gitlab.com/himalaya/lukla-go`，本地目录 `Himalaya/sdk/go/lukla-go`）。本轮通过 SDK 消费现有接口，仅修改 Muskdeer；不改撮合、订单服务、目标协议或 SDK。此前新增的原生网关/协议/迁移路线已撤销。

已核验 SDK 提供 Place、CancelOrder、GetAccountForFund、ListPositionsForFund、ListOrdersForFund 及 Raw 查询接口。价格和下单数量使用十进制字符串。client_id 的关联能力与目标订单幂等保证分别核验；Muskdeer 执行端持久化意图、校验所有权，超时进入 UNKNOWN 后查询，不盲目重发，不将下表的期望能力宣称为撮合已支持。

## 必需能力
| 能力 | 核心字段/行为 | 缺失影响 |
|---|---|---|
| 交易对元数据 | tick、lot、min_notional、状态、币种 | 无法正确报价 |
| 账户余额 | available、frozen、版本/时间 | 无法核实资金 |
| 下单 | client_order_id、账户、方向、数量、价格、TIF、所有权 epoch | 无法真实执行 |
| 订单查询 | 按本地关联标识/核心订单 ID 查询，明确不存在语义 | 无法解决 UNKNOWN |
| 撤单/批撤 | 请求接受与最终完成分离，支持部分成功 | 无法安全停止报价 |
| 有效订单快照 | 可分页及一致性边界 | 无法接管恢复 |
| 订单成交流 | 唯一成交标识、序列、断点恢复或拉取补齐 | 无法可靠投影 |
| 历史成交查询 | 起止范围、分页、去重语义 | 无法对账和重建 |
| STP | 同一自营主体跨账户防自成交 | 无法保证自成交隔离 |
| 失联撤单 | 服务端心跳 TTL、作用域、撤单结果 | 进程失效时旧报价风险 |
| fencing | 交易网关原子验证 epoch，拒绝旧 owner | 严格多节点接管保证受限 |

## 需要提供的资料
仓库/接口文档或 Proto、认证签名规范、测试环境、专用测试账户、限流、错误码、client_order_id 唯一性作用域及保留期、事件序列/重连规则、下单精度、资金冻结及手续费规则。密钥通过本地安全配置注入，不能写入此文档或聊天日志。

## 模拟器
实现上述合同的可控子集并声明能力表。支持固定种子、部分成交、延迟响应、实际成功但响应丢失、撤单竞态、重复回报、乱序、流缺口、余额不足和 epoch 失效。测试由显式事件驱动，不通过长期 sleep 期待随机成交。
模拟器不得自动承诺真实平台支持 fencing、STP 或查询幂等。真实适配器单独运行合同测试，输出通过/不支持/未知的能力矩阵。
