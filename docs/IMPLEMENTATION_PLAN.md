# Codex 实施任务

任务状态以 PROGRESS 为准，本表不预先标完成。每项交付必须包含代码、实际验证证据、运行说明及局限。顺序可因依赖调整，不能省略验收。

## 仓库与逐步交付

公开仓库固定为 https://github.com/hmlax/muskdeer.git，Go module 固定为 github.com/hmlax/muskdeer。每个 Pxx 任务继续拆分为可独立验证的最小步骤，每步按以下顺序完成交付：

1. 实现本步范围并运行对应测试、生成一致性、格式与静态检查；失败先修复，不跳过或降低断言。
2. 更新 PROGRESS，记录本步范围、实际命令、结果及未验证内容；仅暂存本步相关代码、测试、迁移、生成物和文档，保留用户其他修改。
3. 创建清晰关联任务/步骤的提交，立即推送到指定远程的当前工作分支；初始空仓库采用 main，后续遵守实际分支保护规则，不擅自强推或改写历史。
4. 核对远程分支 SHA 与本次提交一致，在交付报告记录 SHA、分支与检查结果，然后继续下一步。推送失败保留提交并解决阻碍，不将该步骤标为远程已交付，也不把后续实现堆到阶段末尾统一提交。

用户已授权上述提交/推送流程，无需逐次确认。文档步骤执行引用、文件完整性等相关检查；尚无业务实现时不伪造 Go 测试结果。P01 核对本地 origin 与指定仓库，已有远程内容须保留并正常整合。

## 交付命令
P02 完成后提供实际可运行的命令：doctor（工具版本和配置检查）、generate、generate-check、fmt、lint、test、test-race、integration、e2e、build、verify、dev-up、dev-down。verify 至少覆盖生成一致性、构建、单元测试及静态检查；依赖容器的检查单列并在 CI 执行。缺工具/依赖时非零退出，不能输出假通过。
P02 将 go.mod 的 Go 版本声明、工具链配置、开发/构建镜像及 CI 同步固定为 1.27.3；doctor 与 CI 检查实际编译器版本精确为 go1.27.3，版本不符非零退出。不得以 1.27、latest 或本机其他版本替代；工具链暂不可获取时记录原因并继续独立文档工作，不静默改版本。
dev-up 仅启动隔离开发资源，端口绑定本机，凭据为明确的开发样例；禁止操作用户已有数据库。dev-down 默认不删除卷。

## 代码与审查门禁
每个任务关联需求 Rxx 和验收 Axx。订单/预算/lease/重复消息及故障恢复必须有行为测试；低影响文档不需要镜像实现的测试。新增依赖说明必要性、许可证、版本及兼容验证；不为框架清单引入未使用服务。
公共服务封装关联 R09、A02/A26：P02 实现 deer.NewDeer 与 deer.NewDeerApi，所有业务服务分别通过 Deer 装配，API 通过 DeerApi 复用其依赖与生命周期；公共 config/model/common Proto 统一在 deer/proto。初始化失败与正常停止均验证单次资源释放，不能只完成类型命名。
数据库变更必须通过 A01/A22：所有表含 Id 自增主键、createAt/updateAt NOT NULL、deleteAt 可为 NULL；所有 GORM 数据操作显式绑定生成 Model。verify/CI 禁止任何 DB 变量上的 .Table(...) 及封装绕过，不因脚本或测试而豁免。
接口及小数计算必须通过 A23：所有接口小数字段统一 string，Go 小数统一 decimal.Decimal，禁止 float32/float64 及浮点中转。P01 统一 decimal 库并锁定版本，P03 落实到生成合同及模拟器；验证高精度字符串、舍入、非法输入与数据库 numeric 往返，并将静态检查纳入 verify/CI。
行情需求关联 R01/R02/R04、A04/A05/A24/A25：P03 定义实例来源字段与模拟合同，P05 实现 Binance/OKX 两家适配，P07 完成所有策略模板的选择和切换 API。Bitget/Bybit 仅为候选，不计入首批完成条件；A25 公共行情实连可在 P05 独立执行，不必等待私有交易账户，模拟通过不能代替实连证据。

## 首轮的具体工作
1. 读取现有文件和 git 状态，核对 origin 为指定仓库及分支状态，确认包未覆盖现有实现；按逐步交付流程提交并推送首个验证完成的步骤。
2. 获取并核验用户固定的 Go 1.27.3 工具链及依赖兼容；如果网络不通，记录失败并继续本地可执行部分，不猜 API 或替换 Go 版本。
3. 用一个小型模型验证 Proto→GORM→PostgreSQL；保留生成前后的样例和可复现命令。
4. 产出工具版本锁定及 ADR；生成路线不符合用户约束则集中询问一次，暂停依赖该路线的工作。
5. 实现基础设施装配和模拟交易闭环；不要先创建所有服务的空方法当作阶段完成。
